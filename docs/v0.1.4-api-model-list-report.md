# v0.1.4 API 配置模型列表交互

日期：2026-10-09。版本继续保持 0.1.4。

在“设置 → API 配置”中，获取模型后点击候选模型，只收起模型列表，配置编辑区继续保留；选中的 ID 显示在原来的模型 ID 输入框中。手动填写自定义模型后点击“选择”也只收起列表。选择过程中不保存 Profile、不启用新连接、不关闭设置窗口。

名称、API 地址、输入的密钥、思考、价格、附加参数等草稿保持原值，可继续编辑。已获取列表可通过“展开模型列表”重新打开，不重复请求接口；需要最新数据时在列表中点击“刷新列表”。仅返回一个模型也等待用户明确选择。

修改完成后由原有“保存配置”或“保存并启用”生效，保留已有逻辑：保存当前已启用的 Profile 会同步当前连接；保存其他 Profile 不自动启用。关闭未保存的编辑仍先提示放弃或继续编辑，放弃后不改变原配置；保存失败保留编辑草稿并显示错误。

- tests/api-model-picker.test.ts：草稿保留与明确保存、失败保留、单模型不自动选中。
- tests/browser/api-model-picker.spec.ts：设置窗口保持打开、继续修改思考／价格／附加参数、缓存重新展开、自定义选择与放弃修改、640×480 窗口布局。
- README、CHANGELOG、总验收报告、发布收集脚本：交付记录。
