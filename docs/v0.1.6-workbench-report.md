# ClaudeChat v0.1.6 工作台 UI 重构

2026-10-30，版本保持 0.1.6。此次仅修改 `App.vue` 的导航布局和入口绑定、增加 `workbench.css` 并引入该样式；未修改聊天 Store、Provider、API 请求、数据结构、数据库或 Rust 源码。

## 改动区域

- 宽屏增加 56px 窄图标轨，提供聊天、统计、历史搜索、设置入口，全部调用原有页面切换或打开逻辑。详细侧栏继续保留新建、六类服务、统计、历史和设置。窗口不足 1180px 时隐藏额外图标轨，保留原有完整入口；不足 760px 时沿用紧凑侧栏。
- 工作区增加 8px 外层留白，详细侧栏和聊天表面分为柔和圆角面板。侧栏菜单统一 40px 高、8px 圆角、固定图标间距；新建按钮保持绿色突出。历史按原有时间分组，选中状态采用柔和强调色底与细左侧条。
- 顶部采用轻量背景及弱分隔线，标题与操作按钮对齐。保留对话树和更多菜单中的现有操作，没有添加无实际行为的分享按钮。
- 正文沿用 800px 阅读宽度，统一标题、段落和列表间距。现有 Markdown 引用块采用浅色信息卡片，不根据文字内容猜测结论、不修改模型输出。消息工具栏统一 32px 按钮与 4px 间距。
- 输入区成为居中的 20px 圆角悬浮卡片；模型、思考、联网控件统一边框、高度和间距；发送按钮为克制的绿色，底部辅助提示降低视觉权重。保持 IME、快捷键和发送规则。
- 继续使用既有 8 套主题变量、语义色、Motion Tokens 和减少动画设置。小高度侧栏独立滚动，避免入口落到窗口外；窄窗口允许输入选项自然换行。

## 验证与界限

完整结果与构建清单见 `installers/v0.1.6-workbench/verification.json`，界面效果图见该目录 `screenshots/`。生产包继续使用 v0.1.6 的现有 NSIS 配置。

UI 回归包含浅/深主题、全部配色、缩放、搜索、模型切换、IME、草稿、长回答、对话树、Minimap、Usage 和设置关闭。新的工作台用例验证图标轨实际操作、640×480 收缩及横向溢出，并使用仅存在于测试内存中的示例消息生成截图；截图不是用户的真实会话。

此次是有意的布局更新，因此 Usage 的旧“占满除 Sidebar 外所有宽度”断言改为核对工作区右边缘与外层留白；输入控件高度断言对应统一后的 36px。未放宽业务行为断言。

Windows 100% / 125% / 150% 使用浏览器和生产 WebView 的设备缩放仿真验证，不改动 Windows 系统设置。没有宣称完成多台实体显示器、帧率或功耗实测。
