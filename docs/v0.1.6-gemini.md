# Gemini API 接入（v0.1.6）

客户端新增独立 Gemini Chat 服务，使用 Google 官方提供的 OpenAI 兼容端点和 Google AI Studio API Key。版本号仍为 0.1.6，无需安装 Google SDK。

## 配置

1. 打开设置 → API 配置 → 新建，服务类型选择 Gemini Chat；也可以从侧栏 Gemini Chat 进入配置。
2. 默认地址：`https://generativelanguage.googleapis.com/v1beta/openai`。可点击“使用官方地址”恢复默认值；第三方代理使用其实际兼容地址。
3. 填写 Google AI Studio API Key，点击获取模型，选择账号可用的 Gemini 模型；也支持手动输入模型 ID。
4. 测试连接，保存并启用。连接测试会产生一次有输出上限的请求。密钥仍保存在系统凭据管理器中，不放入 URL。
5. 在输入区选择 Gemini 模型与思考档位，正常发送、停止或上传现有支持的附件。

官方根地址和 `/v1beta` 会补齐兼容路径；完整 `/chat/completions` 地址及代理的 `/v1` 路径保留。此实现的网络协议是 Google 的 Chat Completions 兼容接口，不直接调用 `generateContent`，也不使用 Vertex AI 服务账号认证。

## 能力

- 模型列表、连接测试、文本和图片输入、文档提取文本、流式输出、停止、恢复与重启后续写。
- 复用 Profile、API Key、模型单价、Usage、上下文及分支保存机制，无数据库结构迁移。
- 思考档位映射 `reasoning_effort`；2.5 Flash 等支持时 off 发送 none，不能关闭思考的模型使用 low，旧非思考模型省略该参数。自定义 `extra_body.google.thinking_config` 优先，不能同时显式配置两个思考参数。
- 首轮标题使用同一 Gemini Profile，独立预留 2048 Token 输出预算，保持一次尝试及手动名称优先规则。
- 联网使用现有 SearXNG。此版本不把 Google 原生 Grounding 视为已实现的 Chat Completions 搜索工具。
