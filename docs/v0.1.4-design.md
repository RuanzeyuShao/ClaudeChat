# v0.1.4 设计与实现说明

## 组件边界

- `ActionMenu`：边界定位、外部点击、Escape、箭头键与菜单焦点。
- `BaseModal` / `FeedbackHost` / `ui`：可访问弹窗、文本输入与确认、焦点恢复、Toast、统一错误映射。
- `ConversationTree`：迭代构建、SVG 连接线、折叠、当前路径、定位与固定行高虚拟列表。
- `ChatInput`：IME、发送偏好、按会话草稿、异步附件解析、编辑展开。
- `MessageItem`：正文、思考、来源、版本、消息／代码工具和 Usage。
- `DocumentPreview`：图片／PDF／Word／Markdown／代码，以及 Diff 和保存确认。
- `experience` / `codeDiff` / `usageOrigin`：可独立测试的交互规则、差异算法和来源说明。

## 状态与数据

原 SQLite 表、v3 事务迁移、应用标识及凭据命名保持兼容。`v4:drafts` 保存会话草稿和附件，`v4:sendMode` 保存发送方式，`v4:usageOrigins` 保存服务返回字段的来源。后端只放行这三个新增扩展键，API Key 不进入这些数据。浏览器界面预览不持久化，也不会生成假 API 回答。

Provider 应用使用一次 `save_settings` 事务同时保存连接和会话模型；前端仅在成功后更新运行时状态。服务偏好的辅助保存失败会单独提示。流式文本在动画帧内合并，reasoning 状态来自实际 SSE 字段，停止请求完成前保留请求锁。

Usage 输入／输出不自动估算，未返回值记为 0 并标记缺失；思考 Token 根据实际字段或内容估算分别标记。旧记录无法追溯来源，明确显示未标记。费用计算沿用请求时单价，与实际账单区分。

## 视觉与适配

主题集中在 `theme.css`，组件结构在 `style.css`，Provider／设置／Usage 仅保留领域样式。Inter 在本地打包，中文使用系统字体；强调色采用低饱和绿色，各 Provider 保留服务辨识色。

侧栏 68px 图标模式，聊天布局使用容器查询，预览依据中央容器宽度决定覆盖或第三栏；拖动宽度保存在原 localStorage 键。动画 120–220ms，尊重 reduced-motion。输入内容与附件不会存入 localStorage。

## 发布边界

发布产物在 `dist-release/v0.1.4/`。独立 Cargo 目录 `src-tauri/target-v014` 避免迁移目录后遗留的绝对路径缓存。`scripts/collect-release.mjs` 复制当前版本安装包、计算校验、输出清单，不上传远端。

图标依赖采用 Lucide 官方新包 `@lucide/vue`（[官方包名迁移说明](https://lucide.dev/guide/version-1)），未引入大型 UI 或图编辑框架。

## 2026-10-09 同版本布局修复

统计页面的卡片、筛选、图表与明细按实际容器宽度布局，关闭按钮独立于内容滚动区。聊天组件的多根结构使父层 v-show 无法正确隐藏页面，已将可见性移到实际 section，并暂停隐藏期间的滚动及快捷键。统计实例首次打开后保留，筛选与分页不会因返回聊天丢失。

SourceList 只创建前端显示映射，原 sources 与正文不变；规范化 URL 时保留 query/hash，不猜测引用标记。测试明示 `[1] [4]` 合并项仍对应原正文两个引用编号。

## 会话内模型切换修复

完整选择由 Rust 规范化后返回，前端仅接受后端确认的配置；会话当前模型和完整连接快照原子保存，重启优先恢复最后访问的会话。发送时复制配置并分配请求 ID，原始回复来源与 Usage 原子保存，显示和上下文处理不依赖当前可变 Profile。历史未记录的 Provider 明确保留未知。

扩展键新增 v4:conversationConnection:<id>、v4:lastConversation、v4:requestOrigins；不改表结构、不迁移或删除旧数据。原有 save_settings 增加返回配置，旧调用忽略返回值仍兼容；send_message 的可选 requestId 可省略，旧 chat-finished 保留。
