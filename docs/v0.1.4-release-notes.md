Windows x64 桌面对话客户端，应用版本保持 **0.1.4**。

## 下载与安装

在本页 **Assets** 下载 `ClaudeChat_0.1.4_x64-setup.exe`。更新前请退出正在运行的 ClaudeChat，安装后继续使用已有配置和 SQLite 数据。

- `SHA256SUMS.txt`：安装包校验值。
- `manifest.json`：版本、文件大小、构建时间、源码提交与 SHA-256。

## 修复与优化

- 修复用量 Dashboard 宽度、卡片换行、表格内部滚动；支持关闭和 Esc 返回，保留筛选与聊天状态。
- 支持同一会话切换 Claude、GPT、DeepSeek、Kimi、GLM、Grok 的 Provider、Profile 和模型。下一轮使用新配置，保留历史、附件、对话树和原有 Usage；重启恢复连接。
- 选择模型后只收起模型列表，配置面板继续编辑；模型／思考／搜索统一应用。设置中的 API 配置采用相同交互，保留草稿和明确保存。
- 修复聊天服务展开后的横向位移、Thinking 滑块 High 填充和模型配置状态同步。
- 搜索来源去重、保留引用编号，默认展示前三项；明确 Provider API 内置搜索与 SearXNG 的区别和限制。
- 精修正文、代码、公式、主题和工具栏；Composer 模型／思考／联网控件增加字号、描边与分隔，窄窗口自动换行。
- 用户向上阅读时立即暂停跟随，新内容在输入框上方显示“有新回答 ↓”；点击平滑返回，消息末尾和工具栏不被输入框遮挡。

## 验证

前端 46 项、Windows Edge 浏览器 44 项、Rust 39 项回归通过；最后滚动修正另通过 4 项组件和 14 项浏览器复查。Windows x64 NSIS 构建及安装包校验通过。

窗口与 100%／125%／150% 等像素密度测试使用浏览器模拟。外部 Provider 使用本地 HTTP 测试服务，没有使用用户真实密钥或收费 API 做试调用；搜索能力仍取决于所选模型与 API／网关支持情况。
