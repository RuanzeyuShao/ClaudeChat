# v0.1.4 输入框就地模型选择（2026-10-09）

版本保持 0.1.4。

点击输入框底部现有的 Provider／模型按钮，选择面板就在按钮上方打开。面板内提供六个聊天服务的下拉选择、API Profile、模型搜索／自定义模型、Thinking 和搜索设置。选择模型仅收起模型列表，配置面板保持打开；模型、Thinking 和搜索统一点击“应用配置”保存。生成中选择保留为草稿。

无需展开左栏或点击左栏服务入口；左栏聊天服务保持原折叠状态。左栏的入口仍可用于原有快速配置，两个入口共用同一面板和 Chat Store 的后端切换流程，没有复制发送逻辑或修改数据库。

再次点击底部按钮、点击面板外部或 Escape 可关闭，关闭／应用后焦点返回底部按钮。位置按按钮和可用窗口空间计算；监听窗口、输入框尺寸与滚动变化，内容在面板内部滚动，应用按钮保持可见。切换会话会关闭原来的配置草稿面板。

生成中仍能打开面板并选择下一轮草稿；应用锁继续保留，停止／完成后才可切换当前实际配置。

- CHANGELOG、README、验收报告及发布收集脚本：记录本轮同版本交付。
