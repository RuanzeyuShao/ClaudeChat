# v0.1.4 Composer 与长对话滚动

日期：2026-10-09。版本保持 0.1.4。

## 改动

- 模型名称、思考和联网控件统一使用 13px 主字号、38px 最小高度，独立描边、圆角和 8～10px 间距；Provider 名称作为辅助文字，长模型 ID 省略并通过 Hover 查看。控件在窄窗口分别换行。
- 思考控件带图标和配置入口，打开现有配置面板并定位思考滑块；保留模型／思考／搜索统一“应用配置”的草稿流程与生成锁。
- 移除正文上的绝对定位浮动按钮。用户离开底部后，在 Composer 上方独立布局行提供“回到最新”；有新的回答正文、思考或来源等内容到达时改为“有新回答 ↓”。
- 底部自动跟随；向上滚轮、键盘、触摸或滚动立即暂停。排队帧在执行时再次检查跟随状态，避免用户开始阅读后被旧任务拉回。
- 点击提示平滑返回并恢复跟随，生成中的后续内容会在平滑完成后接续跟随。用户向上操作可以中断平滑跳转，迟到的 scrollend 不重新开启跟随。
- 分开消息滚动区与 Composer 固定布局区，设置 Flex 最小高度、末尾留白和内容高度观察；输入区可随草稿扩展，极端内容在输入区内部滚动，正文不会被其覆盖。区分用户阅读和窗口尺寸变化造成的底部位置调整。

- tests/browser/composer-follow.spec.ts：实际 Vue 滚动、提示位置、控件样式与思考入口、消息末尾边界、小窗口及主题／像素密度。
- tests/browser/usage.spec.ts：适配独立提示行，继续验证 Dashboard 返回保留阅读位置。
- README、CHANGELOG、总报告和发布收集脚本：交付记录。
