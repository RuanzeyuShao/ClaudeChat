# ClaudeChat v0.1.4 逻辑修复与交付记录

日期：2026-10-13。版本仍为 **0.1.4**。本轮以当前工作区为基础，保留此前图片与独立网页窗口修复。

## 修复范围

| 问题 | 修复行为 | 回归依据 |
| --- | --- | --- |
| 编辑重发、继续生成校验失败导致历史消失 | 统一发送前校验，校验通过后才改变路径；分支请求失败恢复 SQLite 原叶节点并重新载入；恢复接口失败时保留原界面路径并报告错误。重试继续使用原编辑内容和分支父节点。 | 缺模型、缺密钥、无效搜索设置、API 503、跨会话编辑及重试测试 |
| 历史附件筛选误删本轮新附件 | 筛选只作用于历史消息，当前用户消息及其图片、文档始终作为请求输入保留；重发同样保留当前用户消息的附件。 | Rust 筛选测试，以及 Anthropic / OpenAI 兼容协议的本地 HTTP 请求体检查 |
| 仅思考／搜索预设没有会话持久化 | 合并配置后，在同一笔 SQLite 事务中保存全局配置、当前会话连接快照、会话模型及可选 Prompt；成功后才更新 UI。 | 切换会话恢复；模拟全局配置变化后恢复会话；Prompt 更新失败时整笔事务回滚 |
| 失败预设仍提示成功 | 预设不存在、Profile 已删除／缺密钥、操作繁忙等情况明确拒绝；失败保留配置与预设面板，不触发成功 Toast。 | Store、Vue 组件、Windows Edge 交互测试 |
| URL 去重提前丢失引用 | Rust 保留来源的原始条目和顺序，包括重复 URL；前端合并卡片并保留所有原编号及不同引用标记。Claude 流式引用定位对应当前条目。 | Rust 原始来源顺序与前端 `[1] [3] [4]` 合并映射测试 |
| 允许搜索误显示检索完成 | 根据工具事件、来源及外部搜索结果区分“已允许搜索”“未调用搜索”“检索完成，无结果”“检索完成”“检索失败”“已停止”；检索失败记录错误，刷新后可查看并重试。 | 工具未调用、普通工具、空结果、工具错误、成功来源与状态文案测试 |
| SearXNG 无法及时停止 | 请求响应头和正文读取共用当前请求的取消信号，50 ms 间隔检查；停止后终止检索，不再发起后续模型请求。15 秒超时作为兜底保留。 | 本地 HTTP 服务分别阻塞响应头与正文，验证客户端取消返回；成功和空结果测试 |
| 跨午夜统计范围过期 | 使用响应式日期基准；定时检查、窗口获得焦点、页面重新可见、统计页重新打开和新 Usage 到达均检查跨日；保留模型、Profile、会话及自定义日期筛选。 | 跨月午夜五种触发方式的组件测试及 Windows Edge 重新打开统计页测试 |

## 数据与兼容性

- 沿用 Vue 3、TypeScript、Tauri 2、Rust、SQLite 架构。
- 未改变数据库 schema 或迁移版本；失败请求不新增虚构 Usage 记录。
- 新增预设事务 IPC 命令，原有命令接口保留。
- 历史分支、回答、附件、来源和费用记录不因编辑失败或预设应用而删除。
- `package.json`、`package-lock.json`、`Cargo.toml`、`Cargo.lock`、`tauri.conf.json` 继续使用 0.1.4；既有 Git 标签和 Release 未改动。
