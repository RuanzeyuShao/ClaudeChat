# v0.1.4 模型选择仅收起列表

日期：2026-10-09，版本保持 0.1.4。

列表模型和自定义模型选中后，仅收起包含搜索／候选模型／自定义输入的模型选择区；Provider 配置面板保持打开，已选模型显示在“选择对话模型”按钮上。按钮可重新展开列表，继续选择模型不会重置思考与搜索草稿。

模型选择先记录为草稿；调整完成后点击“应用配置”，由现有 Chat Store 的单次事务保存模型、Profile、Thinking 和搜索，再关闭整个配置面板。应用前输入框始终显示实际使用的模型。直接关闭／Esc 不改变实际配置；应用失败保留草稿与错误提示。生成中允许暂选，停止或完成后才能应用。

## 本轮修改文件

- src/components/ProviderSelector.vue：区分列表展开状态和配置面板状态；选择只更新草稿，统一应用；焦点回到已选模型按钮。
- src/provider-selector.css：模型展开按钮的宽度、标题省略与 Hover。
- tests/model-switch.test.ts：选择后未保存、应用锁与下一轮请求、保存失败。
- tests/browser/selector-regressions.spec.ts：列表／自定义选中后的继续配置、重新展开保留草稿、统一保存模型／思考／搜索、取消不切换。
- tests/browser/composer-picker.spec.ts、model-switch.spec.ts：同步统一应用流程。
- README、CHANGELOG、验收及此前选择报告、发布收集脚本：更新交付说明。
