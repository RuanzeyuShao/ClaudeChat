# v0.1.6 界面信息层级精简

本次调整减少常驻辅助标签，将次要说明移入图标、悬停提示和按需展开区域。版本保持 0.1.6，未修改 Provider、请求、数据库和用量计算。

## 改动

- 输入区不再常驻显示联网判断、上下文计数和快捷键说明。上下文图标通过悬停或键盘聚焦展示联网判断、消息数、附件数及文本 Token 估算；联网模式、模型与思考仍由原控件直接呈现。
- 设置页移除标题下说明、配置数量徽标、已保存文字徽标、字段必填/可选标签和重复成功信息。配置完整度使用状态点；未保存状态使用提醒点；密钥存储、已保存状态和高级参数规则使用图标提示。
- Gemini 的长说明收进服务类型帮助图标；官方地址通过地址行的恢复图标提供。错误、连接测试结果和费用提示仍保留。
- 个性化页面移除重复说明和常驻“已自动保存”文案，选中边框、勾选图标和颜色样本直接表达状态；保存结果继续通过无障碍状态及错误 Toast 提供。
- 用量页移除英文眉题、介绍和“实时更新”标签。统计口径放入可展开的“数据口径”，费用说明仍保留。
- 欢迎页移除重复品牌口号，保留主标题、一个简短说明和三个可执行入口。
- 弹窗焦点过滤改用实际可见矩形，避免隐藏设置页中的可聚焦提示图标干扰 Tab 循环。

## 验证

覆盖 TypeScript、110 项前端单元测试、完整浏览器回归及 Windows NSIS 构建。专项检查包含 Gemini 配置、上下文图标提示、设置焦点循环、全部主题、Usage、紧凑窗口和键盘访问。界面截图位于 `installers/v0.1.6-ui-cleanup/screenshots/`。
