# v0.1.5 字体与会话列表更新

日期：2026-10-14。源码分支：`v0.1.5`。

## 提示布局调整

将输入框上方的返回最新按钮和请求状态放入同一横向容器，垂直居中并保留间距；只出现一项时也保持居中。覆盖 1440×900、800×600、640×480 的浅色／深色布局，以及原有阅读暂停、平滑滚动与输入框固定行为。

## 启动修复

首版安装包的原生扩展键白名单遗漏 `v5:fontSize` 和 `v5:blankConversation`，启动读取字体偏好时返回“扩展键无效”，导致初始化中断。浏览器预览与此前前端测试使用模拟后端，未覆盖原生命令的白名单。

修复仅将这两个明确的键加入白名单，其他未知 v5 键仍被拒绝。新增 Rust 测试直接读取前端 Store 使用的扩展键并核对后端白名单；新增旧数据库写入这两个偏好、重新打开及原历史完整保留测试。

修复验证：Rust 68 / 68、前端 77 / 77 通过，生产构建通过。使用修复后的 Release EXE、真实 WebView2 与 Rust IPC，在隔离 SQLite 中完成首次启动、字体保存、连续新建、进程关闭重启、字体与草稿恢复检查。脚本：`node scripts/native-startup-smoke.mjs`。重新生成同版本 Windows x64 安装包，用户无需删除数据库。

## 功能

- 设置 → 通用偏好新增字体大小，允许输入 12–24 px，默认 14 px。界面、聊天正文、代码和输入框文字按比例调整；桌面端使用 SQLite 扩展持久化，浏览器预览使用 localStorage。字体偏好独立于模型与会话配置。
- 新建对话复用一个未发送消息的会话，保留其输入草稿、附件及 Prompt。按钮与 Ctrl+N 共用此逻辑。切换历史或重新启动后，可以返回该会话；只有已有消息后才创建下一份会话。复用前检查数据库消息树，避免误把尚未加载消息的历史会话当作空会话。旧版已产生的空会话仍保留，可自行删除。
- 浅色主题的侧栏标题使用黑色。长标题默认省略，悬停和键盘聚焦时按照实际溢出距离滚动，末尾停顿后往返；鼠标移开恢复省略显示。短标题不滚动。深色主题使用浅色文字，系统要求减少动态效果时直接展开标题。
- package.json、锁文件、Tauri 配置、Cargo 与界面版本更新至 0.1.5。
