# v0.1.5 字体与会话列表更新

日期：2026-10-14。源码分支：`v0.1.5`。

## 功能

- 设置 → 通用偏好新增字体大小，允许输入 12–24 px，默认 14 px。界面、聊天正文、代码和输入框文字按比例调整；桌面端使用 SQLite 扩展持久化，浏览器预览使用 localStorage。字体偏好独立于模型与会话配置。
- 新建对话复用一个未发送消息的会话，保留其输入草稿、附件及 Prompt。按钮与 Ctrl+N 共用此逻辑。切换历史或重新启动后，可以返回该会话；只有已有消息后才创建下一份会话。复用前检查数据库消息树，避免误把尚未加载消息的历史会话当作空会话。旧版已产生的空会话仍保留，可自行删除。
- 浅色主题的侧栏标题使用黑色。长标题默认省略，悬停和键盘聚焦时按照实际溢出距离滚动，末尾停顿后往返；鼠标移开恢复省略显示。短标题不滚动。深色主题使用浅色文字，系统要求减少动态效果时直接展开标题。
- package.json、锁文件、Tauri 配置、Cargo 与界面版本更新至 0.1.5。
