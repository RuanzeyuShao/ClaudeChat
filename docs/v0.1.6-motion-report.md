# ClaudeChat v0.1.6 Motion Design System

版本保持 **0.1.6**。本次是同版本的交互优化构建。最初按要求独立交付，经用户于 2026-10-26 确认后，已更新现有 v0.1.6 GitHub Release 的安装包和正式资料 `installers/v0.1.6/`；`installers/v0.1.6-motion/` 保留专项测试资料。已有 Release 标签不移动。

## 统一规范

`src/motion/tokens.css` 是动画时长和曲线的唯一定义：Fast 120ms、Normal 180ms、Slow 260ms、Data 450ms；缓动为 `cubic-bezier(0.2, 0, 0, 1)`。Minimap 依照既定行为保留 150ms 的宽度过渡和原有 `ease`。

`motion.css` 集中管理共享界面动效、颜色过渡和减少动画规则。`runtime.ts` 统一管理少量 Web Animations、可见性和系统偏好监听；新动画替换同元素的旧动画，完成、取消、卸载及窗口进入后台均有清理。没有增加 npm 或 Cargo 依赖。

运行时读取 CSS 时间时同时支持 `ms` 和 `s`，避免生产压缩将 `180ms` 序列化为 `.18s` 后误当成 .18 毫秒；浏览器回归验证单位换算，生产 WebView 回归验证真实离场节点在 50ms 后仍然存在且已 inert。

## 已实现的交互

| 模块 | 行为 |
| --- | --- |
| 侧边栏 | 260ms 调整宽度，让正文同步获得空间；图标采用有数量上限的 FLIP 校正，文字轻量渐隐/渐显；支持连续反向点击，拖动分隔条时关闭补间。 |
| Provider / 模型 | 面板透明度与向上 6px 的 180ms 进退场；模型选中背景、Thinking 滑块、联网状态统一过渡，沿用现有成功 Toast。离场节点立即 inert，保留输入焦点、Escape 和外部关闭。 |
| 消息 / 生成 | 新用户消息向上 6px 渐入，AI 容器仅首次淡入；历史会话不重播入场，流式内容不逐 Token 动画。连接、搜索、思考、生成和自动续写使用不同状态图标；停止和卸载结束循环。自动恢复沿用现有动态提示，不改重试规则。 |
| 按钮 / Composer | Hover 背景与边框 120ms，按下 scale(.97)，焦点边框和阴影柔和变化；发送/停止图标轻量切换，禁用按钮无按压及可点击 Hover 反馈。没有改变 IME、发送方式和快捷键处理。 |
| Minimap | 默认全部 6px，仅 Hover 行变为 18px / 150ms；预览卡片同步淡入，离开收起；当前位置只改颜色，点击平滑定位。保留原滑轨布局和正文避让。 |
| 弹窗 / 菜单 / Toast | Modal 淡入和 .98→1，Dropdown 4px 位移，Toast 6px 上浮；Tooltip 延迟出现避免连续闪烁。弹窗进入/退出与业务开关同步，离场内容不再参与焦点捕获。 |
| 对话树 | 保持原 62px 行高及 18 行虚拟窗口，折叠分支时行移动/淡入；路径颜色、节点 Hover 过渡。整个面板 260ms 展开/收起，不插入延迟修改活动分支的定时器。 |
| 搜索来源 | 搜索状态低频呼吸，来源首次淡入；列表展开/收起采用有界高度补间，卡片边框/阴影变化；引用预览使用现有来源标题，点击仍走原链接处理。 |
| 附件 / Diff | 拖入高亮、解析 Loading，附件增删淡入/淡出，附件组高度平滑变化；Diff 切换保留 scrollTop/Left，并用短淡入缓解整块闪动。 |
| Usage | 数字首次从 0 到真实值；折线初次渐进显露、后续坐标插值；横向柱形从基线 scaleX 增长。筛选过渡保留 Dashboard 实例和滚动，交互图表时立即落到真实值。 |
| 主题 | 全部 8 套颜色主题，Light / Dark / Follow System 的共享表面 180ms 颜色过渡。启动前应用缓存主题并关闭启动过渡；保留语法高亮、警告和错误语义颜色。 |
| 历史列表 | Hover、选中指示、标题更新、置顶与分组变化提供轻反馈；仅针对可见且有上限的相关元素，不对整个长列表逐项播放。 |

## 数据与性能边界

- 动画主要使用 transform / opacity。侧边栏宽度及树、来源、附件面板高度是同步布局所必需的少量例外；高度只在状态切换前后测量，不在每帧反复读取布局。
- Usage 的动画数组属于展示层；原 `stats`、筛选、Token、费用及 SQLite 数据保持真实值。辅助技术标签、数据属性和图表交互提示直接使用真实统计值，插值在完成时精确收敛。
- 超过 500 条 Usage、80 个时间桶或 40 个分组关闭数据补间；超过 300 个树节点关闭行移动动画；超过 24 组来源关闭列表补间。Sidebar 最多校正 16 个图标、保留 24 个短暂文字快照。
- 媒体偏好变为 `prefers-reduced-motion: reduce` 时，关闭非必要 CSS 动画，结束已注册的 Web Animations 和数值补间，导航使用即时滚动。后台窗口暂停循环并结束展示补间。
- 流式渲染只更新现有消息内容；入口指令仅在容器挂载时运行。复制反馈、Diff、Tooltip、观察器和帧任务均在取消或卸载时释放。
- 未修改 Rust、Provider Adapter、API 请求、对话树存储和 Usage 计算规则；聊天 Store 唯一调整是滚动行为尊重系统减少动画偏好。

## 复现

```powershell
npm run typecheck
npm test
npm run test:ui
$env:CARGO_TARGET_DIR = 'D:\claude-chat\src-tauri\target-v014'
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri:build -- --bundles nsis
node scripts/native-startup-smoke.mjs src-tauri/target-v014/release/claude-chat.exe
node scripts/native-recovery-smoke.mjs src-tauri/target-v014/release/claude-chat.exe
node scripts/native-title-smoke.mjs src-tauri/target-v014/release/claude-chat.exe
node scripts/native-motion-smoke.mjs src-tauri/target-v014/release/claude-chat.exe

```

浏览器回归默认独立使用端口 14320；可通过 `CLAUDECHAT_TEST_PORT` 指定其他空闲端口，禁止复用已运行的其他项目。生产包编译仍有既有大 chunk 和未使用 Rust 函数警告，没有作为本次范围引入打包拆分或业务修改。
