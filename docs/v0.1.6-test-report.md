## 2026-10-23 AI 标题更新（版本仍为 v0.1.6）

- 移除首条用户消息截取命名。新会话第一次发送时在 SQLite 中预留一次性标题任务，首轮正文请求结束后，在后台用第一次请求的服务与模型生成短标题。
- 追问、继续、重新生成、重启，以及删除首轮后再发消息，都不会重新请求标题。旧会话不补生成；手动改名优先，迟到结果不会覆盖手动标题，也不会恢复已删除会话。
- 输入只包含最多 4000 字符的首条文字，以及最多 4 个附件的文件名与各 600 字符文字片段，不发送图片 base64。关闭联网与额外思考，最多输出 128 token，超时 15 秒；只发一次 HTTP 请求，不自动重试。
- 标题失败保留“新对话”，提示可以手动改名，不影响正文。首轮主动停止、或标题任务开始前已手动改名/删除时跳过，不在下一轮补调用。进程退出后未完成的标题也不自动补调用。
- 标题调用独立记账，用量明细及详情标注“AI 标题”；返回的 token 记为服务商数据，缺失数据标记不可用，不伪造实测值。
- 验证：110 项前端单元测试、105 项 Rust 测试、21 项浏览器回归通过；前端及 NSIS 构建通过。真实生产程序（临时数据目录、本地模型服务）验证了首次一次、正文先返回、重启不重复、手动改名竞态、失败不重试、附件摘要、独立用量显示、删除竞态；原有启动和长回答恢复验证也通过。

## 数据与兼容

- 当前 SQLite user_version 为 7（初始 v0.1.6 为 6），新增一次性标题任务表。旧消息、标题、分支、附件、Profile 和账单保留；迁移可重复执行，失败回滚。
- 新目录通常为 `%APPDATA%\com.ruanzeyu.claudechat`。旧 `%APPDATA%\ClaudeChat` 库保留作升级前备份；清库仅处理当前数据库和凭据，不删除旧备份、导出文件。
- 删除一轮包括同问题的回答版本和后续分支，普通删除保留账单。
- token 为文字字符估算，不含模型特有的图片计费。费用只累计已回传/估算并记账的调用。
- 检索意图使用本地规则，不额外调用模型；用户可为下一条消息覆盖联网模式。
