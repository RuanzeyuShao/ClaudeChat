| B4 删除孤儿数据 | 会话删除事务同步清理树、附件、草稿、上下文、连接快照及相关来源，保留历史账单。配置删除清理对应快照/来源，维护按钮清理未引用缓存、附件与来源。 |
| C1 平台/目录 | app.path().app_data_dir() 解析失败报错；旧目录用 SQLite VACUUM INTO 一致性复制，已有目标不覆盖。发布限定 Windows NSIS，字体目录从 SystemRoot 获取，不宣称跨平台支持。 |

| D1 删除与清库 | 菜单永久删除此轮及后续分支，确认说明范围；清空当前数据库先确认再输入“清空”，包含配置、凭据与账单。提交失败恢复凭据。 |
| D2 旧回答重新生成 | 快捷按钮仅末条显示；store 对任何非末条生成加确认，取消保留路径，确认后创建新版本。 |

## 数据与兼容

- SQLite user_version 更新为 6。旧消息、分支、附件、Profile 和账单保留；来源与草稿迁移可重复执行，失败回滚。
- 新目录通常为 `%APPDATA%\com.ruanzeyu.claudechat`。旧 `%APPDATA%\ClaudeChat` 库保留作升级前备份；清库仅处理当前数据库和凭据，不删除旧备份、导出文件。
- 删除一轮包括同问题的回答版本和后续分支，普通删除保留账单。
- token 为文字字符估算，不含模型特有的图片计费。费用只累计已回传/估算并记账的调用。
- 检索意图使用本地规则，不额外调用模型；用户可为下一条消息覆盖联网模式。
