# v0.1.4 实施计划

基于 v0.1.3 的现有 Pinia、SQLite 事务迁移、Provider Adapter 与 Tauri command 实施。

1. 统一设计变量与基础 UI：Lucide、菜单、可访问 Modal、Toast。
2. 修复 Provider 打开即切换；将应用连接改为单次设置事务，保存失败不改变当前连接。
3. 聊天头部精简；消息排版、代码工具、折叠用量；输入框草稿、IME、展开、附件状态。
4. 路径高亮、折叠与虚拟列表对话树；滚动跟随与回到底部；流式状态。
5. 侧栏分组、菜单、图标模式、快捷键；设置与 Diff 确认流程；Usage 来源标记。
6. 新交互自动化、Vue/Rust 回归、窗口/主题检查、NSIS 构建、校验与交付报告。

不改应用标识、凭据命名和旧表结构；新增偏好、草稿与 Usage 来源使用 settings 扩展命名空间。草稿包含用户内容与附件，仅写 SQLite，浏览器预览不持久化。完整构建与截图产物存入 dist-release/v0.1.4；按用户后续要求，最终源码和安装包提交到 GitHub 的 v0.1.4 分支，不创建或修改远端 Release／已有标签。
