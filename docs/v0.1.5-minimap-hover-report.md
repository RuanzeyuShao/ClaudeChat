# v0.1.5 滑轨位置与 Hover 修复

日期：2026-10-15。版本号保持 0.1.5，仅修改前端导航组件、CSS 和交互测试；数据库及 Provider 不变。

## 位置与严格宽度

滑轨绝对定位于聊天区左边缘 6 px 处，不再跟随居中正文移动。透明命中区域宽 26 px，实际横线在其内部偏移 2 px。窄窗口正文最小左间距为 56 px，展开横线右端到正文仍有 30 px；宽窗口沿用既有正文居中布局。轨道不参与普通文档流，不创建带背景的侧栏。

每条横线都是同一种 `.minimap-line`：默认宽 6 px、高 2 px，相邻视觉间隔 8 px。只有 `.is-hovered` 可以设置宽度 18 px，使用 `transition: width 150ms ease`。`.is-current` 仅改变颜色和透明度，角色、点击和阅读索引不参与宽度计算；鼠标移开立即移除预览，横线在 150 ms 内恢复短线。轨道在键盘聚焦时也没有框住整条轨道的明显边框。

## Hover 与完整内容

每行透明命中区域扩大到 26×8 px，中间仍保留不触发 Hover 的空隙。宽度动画不会改变命中范围，因此移动到延长横线或透明边缘时不会闪烁。

预览始终放在对应横线右侧，采用深色浮层并适配 Light / Dark。包含角色、摘要、消息序号和百分比；在实际尺寸测量完成后显示，限制在窗口和消息阅读区内，不越过侧栏或输入框。

短用户问题直接完整展示；长问题最多预览 1000 字符、8 行，若被字符数或窗口高度截断，提示“点击该横线查看完整问题”。点击沿用消息导航，定位到保存的完整原文，不额外新增弹窗或改变问题内容。AI 回答显示紧凑摘要。

同一消息的 Hover 在正常流式更新期间保持稳定；鼠标离开后立即隐藏预览，不依赖点击或阅读选中状态。折叠、短会话、切换分支和隐藏聊天页会清除旧预览。

## 定位与性能

点击和键盘定位使用真实消息 DOM 偏移进行平滑滚动；尊重系统减少动态效果设置。滚动过程中持续更新真实阅读位置，而不是先把目标当作当前位置。拖动仍即时覆盖整个分支，普通滚轮保持正常阅读体验；用户输入可以中止程序滚动。

固定 8 px 间隔不能把任意多消息压进同一高度，因此轨道采用最多 24 条标记的可见窗口。每条标记明确映射一条当前分支消息，阅读超出窗口后更新可见范围；拖动、Home/End 仍可访问完整分支。标记 DOM 数量有上限，滚动采用 requestAnimationFrame 和二分定位，内容变高时由 ResizeObserver 合并更新偏移。

## 验收

- Light / Dark；1440×900、800×600、640×480。
- 默认、移开、点击后、手动滚动后的全部横线宽度为 6 px；仅 Hover 一条为 18 px；高度 2 px、间隔 8 px、150 ms ease 动画。
- 空隙无预览、不误跳转，扩大透明命中区域内移动预览保持稳定。
- 展开横线与正文间距至少 24 px，轨道贴近聊天区左缘，预览始终在右侧并在窗口和消息区内。
- 点击后真实消息滚动到指定位置，手动滚动更新颜色高亮；宽度不因当前位置改变。
- 长问题的完整原文入口、流式预览稳定、拖动、键盘、滚轮、折叠、长短会话和分支切换。
- 120 条消息下只渲染最多 24 个标记，未创建全量历史的重复节点。
- 前端单元回归：88 / 88 通过；完整 Windows Edge 回归：65 / 65 通过。
- 补充复核三个尺寸下的聚焦状态、6 / 18 px 宽度、150 ms 动画、平滑定位和正文间距：3 / 3 通过。
- TypeScript、Vite 生产构建、Windows x64 NSIS 构建通过；实际 Release EXE 在隔离数据库中通过启动、字体偏好保存和重启草稿恢复检查。
