# v0.1.4 聊天服务／思考滑块／模型选择修复

日期：2026-10-09。版本保持 0.1.4。

## 修复

1. **展开服务导致横向位移**：Sidebar 同时输出 aside 和分类弹窗，父组件传入的 style 无法自动传递给多根组件。浏览器复现中配置宽度为 264px，实际只有 225.4375px，且依赖内容。改为显式 width 属性并绑定到 aside，展开服务不再参与宽度计算；历史区域用稳定滚动条槽，防止出现滚动条时改变卡片宽度。
2. **High 留有未填满轨道**：原生 range 继承了普通输入框的内边距、边框与焦点效果。独立设置轨道、进度与滑块，Off／High 分别映射 0%／100%，支持鼠标、触摸和 Home／End／方向键四档操作，应用后重开恢复。
3. **点击模型没有生效反馈**：原列表只修改草稿，实际连接需另按应用。现在空闲时点击模型即调用 Chat Store 原有原子保存，确认成功后关闭面板、更新实际标签与 Toast；保存时锁住控件，避免双击／其他选择与请求错位。失败时面板显示错误，实际 Provider、模型、历史和下一轮请求保持原配置。

生成中仍能查看并暂选模型，但不修改当前请求，也不会在回答结束后悄悄自动切换；停止／完成后按“应用配置”生效。最新同版本交互为：列表或自定义模型选中后仅收起模型列表，配置界面继续保留；模型、思考与搜索统一应用，详见 v0.1.4-model-list-report.md。

- `tests/browser/selector-regressions.spec.ts`：侧栏布局、即时应用／失败反馈、100%／125%／150% 像素密度模拟、滑块端点和保存恢复。
- `README.md`、`CHANGELOG.md`、验收报告、就地选择报告与 `scripts/collect-release.mjs`：说明和交付记录。

## 验证结果

- Vue／TypeScript 生产构建通过。
- Vitest 34 项通过，Rust 39 项本轮重新运行通过，Windows Edge Playwright 32 项通过。
- 用短历史和 40 条历史分别反复折叠服务，测量侧栏、聊天区域、输入框、历史标题和列表的 x 与宽度保持不变；整体侧栏折叠为 68px 后恢复到 264px。
- 滑块 Off／Low／Medium／High 的值和进度正确，High 应用后重开恢复，面板固定页脚不遮住滑块；实际 Vue 截图位于 `screenshots/selector-high-1.png`、`selector-high-1.25.png`、`selector-high-1.5.png`。

像素密度检查是本机 Edge 的 deviceScaleFactor 模拟，不等同 Windows 设置中的原生 DPI 验收；本轮没有控制或替换正在运行的用户客户端，也没有使用真实收费 API。底层 Rust Provider Adapter／数据库逻辑未改动，仍通过本地 HTTP 路由与 SQLite 回归验证。无标签或远端 Release 修改。
