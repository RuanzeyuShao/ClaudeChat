# v0.1.4 UI/UX 修复记录（2026-10-09）

版本仍为 0.1.4。本轮不改 Rust 后端、API 接口、数据库、Usage 计算或已有标签／远端 Release。

## 根因与修复

1. 聊天页有多个根节点，父组件施加的 `v-show` 无法作用到实际页面根节点，统计页打开时聊天仍并排占宽。显隐控制移至 ChatView 的真实 section，隐藏期间不处理 Esc 或自动滚动。
2. 统计卡片使用窗口媒体查询和固定列最小宽度，没有考虑侧栏占用。改为 `auto-fit + minmax(min(100%,146px),1fr)`，依据实际容器宽度换行。
3. Dashboard 缺少明确高度与滚动边界。现在为 flex column，section／滚动区显式 min-width/min-height:0，只有内容区纵向滚动；关闭按钮固定在内容滚动区外。
4. 筛选器、比较图、卡片和 SVG 使用可用宽度；SVG 坐标、刻度数量和 Tooltip 随容器宽度更新，表格单独拥有水平滚动容器。
5. 统计页面曾在退出时被卸载。现首次打开后保留实例；关闭和 Esc 返回聊天，保留筛选、日期、分页、图表缩放、草稿与阅读位置。嵌套弹窗的 Esc 先关闭弹窗，不同时退出 Dashboard。
6. 来源卡片合并规范化后的重复 HTTP(S) URL，默认显示三个不同链接；每个合并项保留原编号及 Provider 标记，如 `[1] [4]`。不改写 Markdown、原始 sources、数据库或搜索计数。查询参数和页面锚点保留，避免错误合并不同资料位置。
7. Markdown 段落、代码和公式排版微调；模型与 Thinking 成组，联网控件自动换行，发送按钮始终保留；工具栏补齐 Hover 和标题提示。

## 验证结果

- `npm run build`：TypeScript 与 Vue 生产构建通过。
- `npm run test`：24 / 24 通过；包含原有交互测试与新增 3 项来源测试。
- Rust：33 / 33 通过，原有测试保留，本轮未改后端。
- `npm run test:ui`：20 / 20 通过。
- 填充统计数据和长标题的 Light／Dark 页面，Windows Edge 浏览器在 100%／125%／150% deviceScaleFactor 下运行，验证 800×600 到 640×480 缩放、侧栏展开与收起。
- 逐张滚动统计卡片检查可见、未横向裁切；验证表格水平滚动只在表格容器内；图表 Tooltip 不越出图表。
- 验证统计页占据完整剩余宽度、聊天页确实隐藏；按钮关闭、Esc、嵌套详情与 Provider 面板关闭；再次打开保留筛选，返回聊天保留草稿、树和长对话阅读位置。
- Windows x64 NSIS 安装包重新生成，文件版本为 0.1.4，发布目录 SHA-256 同步更新。

截图 `usage-fixture-light/dark-100/125/150.png` 来自浏览器测试的内存样本，不是用户真实账单；测试注入只在 tests 中，发布应用仍从 SQLite 读取真实 Usage。前轮截图中聊天与统计并排的问题已通过截图复核发现并修复，最终截图已更新。

Windows 浏览器缩放模拟不等同于修改操作系统 DPI。未执行收费 Provider 请求、安装／卸载现有软件或改变 Windows 显示设置；原生桌面交互验证结果以最新验收报告为准。


## 实机验证边界

更新后的构建路径进程与 ClaudeChat 窗口已启动，UI Automation 读取到已有历史、新版来源前三项及展开入口。尝试点击统计入口时工具返回 coordinate input geometry is unavailable；随后截图捕获返回 FrameArrived timed out: timed out waiting on channel，按恢复流程重新选择、激活窗口后返回 window capture timed out: timed out waiting on channel。已停止实机自动化。原生窗口的关闭／缩放不能据此标为通过；完整关闭和布局回归由 Windows Edge 的 20 项自动化验证覆盖，100%／125%／150% 是浏览器 deviceScaleFactor 模拟。
