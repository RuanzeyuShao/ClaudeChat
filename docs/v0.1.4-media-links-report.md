# v0.1.4 图片加载与链接返回修复

日期：2026-10-10（Asia/Shanghai），版本保持 0.1.4。

## 原因与修复

截图中的图片指向 `Pillars of Creation in Eagle Nebula.jpg`。对该 Wikimedia 文件进行只读核对，官方 imageinfo 接口返回 `missing`，图片 URL 返回 404；这不是 CSS 可以恢复的图片。消息中的原始文字和链接继续保留，客户端不改写历史回答。

- 正常远程图片通过 Rust 下载器加载，处理 HTTP 重定向及 Wikimedia 文件页地址，校验图片格式和大小后显示；使用有界会话缓存，避免流式重绘时重复下载。
- 加载失败明确显示不存在／拒绝／非图片地址等原因，隐藏破图图标，提供重试和打开原链接；支持大图预览及“返回聊天”。当前支持 PNG、JPEG、GIF、WebP、AVIF，其他格式或超过 12 MB 的图片可打开原链接查看。
- 历史上传图片没有携带内联数据时，缩略图按需读取已保存附件，不再生成 `base64,undefined`。输入框和消息附件共用缩略图组件。
- 消息正文、来源卡片、Markdown／Word 预览中的网页链接统一拦截，桌面端在独立网页窗口打开，顶部菜单提供“返回聊天”（Esc）和“在系统浏览器打开”。关闭预览窗口会聚焦原主窗口，聊天页面、草稿和阅读状态保留。
- 主窗口限制到应用／开发地址，网页窗口不允许执行应用命令；图片下载器检查协议、地址、重定向、图片签名、超时与体积，不携带 Provider API Key。
- 回归中修正窗口放大同时收到新内容时误暂停跟随的问题，滚轮、键盘、触摸和滚动条操作仍可以立即暂停。

- tests/media-links.test.ts、tests/browser/media-links.spec.ts：图片／链接及数据保留回归。
- CHANGELOG、验收报告、发布收集脚本：记录本次同版本安装包。

## 验证结果

- Vue／TypeScript 生产构建通过；前端 51 项、Rust 45 项、Windows Edge 浏览器 47 项通过。
- 图片重定向、真实二进制格式校验、404 和 HTML 地址、地址边界、请求合并、重试恢复、旧附件数据读取、图片预览返回、正文／来源链接调用以及原消息／草稿保留均有回归。
- Windows 原生启动使用独立 APPDATA 测试库，没有写入用户实际聊天库。原生无障碍状态确认有效 Wikimedia JPEG 已加载（可用的大图按钮），缺失图片显示 404 提示，测试草稿仍在。
- 原生点击工具返回 `coordinate input geometry is unavailable`，截图捕获返回 `FrameArrived timed out: timed out waiting on channel`；随后用户用物理 Esc 停止 Computer Use。本轮没有继续窗口操作，不能将原生“返回聊天”菜单点击验收标为通过。菜单代码已编译，链接调用及图片弹窗返回通过浏览器测试验证。
- Windows x64 NSIS 安装包已重新生成，版本 0.1.4，附 SHA-256。数据表、API／消息请求格式、对话树、原始 Usage 和历史回答未修改，未调用收费 Provider。
