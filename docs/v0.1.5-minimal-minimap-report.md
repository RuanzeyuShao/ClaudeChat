# v0.1.5 极简消息轨道优化

日期：2026-10-15。版本号继续为 0.1.5，数据库和 Provider 逻辑不变。

## 外观

`ConversationMinimap.vue` 保留单一 Canvas，轨道宽度从 22 px 收窄到 18 px，没有面板背景、边框、阴影或视口色块。横线按当前分支的消息顺序均匀排列，高度随消息数量收缩，最高 220 px；两条巨大消息也只有约 19 px 的轨道，消除按段落像素高度投影造成的巨大空隙。

轨道绝对定位在正文左侧的现有间距内，宽窗口贴近正文边缘，窄窗口最多使用 26 px 的正文左间距。其他横线为低对比浅灰，当前阅读位置较长较亮，Hover 横线单独高亮。折叠控件弱化，仅在 Hover 或焦点操作时出现，折叠后保留展开入口。

## Hover 与定位

- 默认不创建预览卡片。以横线的实际纵坐标和宽度命中测试，横线之间的空隙不显示预览；点击空隙不跳转。
- 预览卡片使用 Teleport 与固定定位，包含用户 / AI、摘要、消息序号及大致百分比。先测量再显示，避免初次出现在页面角落。
- 优先利用正文左侧空隙；空间不足时在轨道旁显示紧凑卡片。卡片被限制在聊天阅读区和窗口边界内，避开侧栏、输入框与页面裁剪。
- 移开、滚动、拖动、折叠、切换分支或隐藏聊天页面时立即隐藏预览；轨道因窗口或输入框改变位置时也清除过期 Hover。
- 点击横线立即定位对应消息，拖动覆盖整个当前分支；ArrowUp/Down、Home/End、PageUp/Down 保留。轨道上的滚轮转发到消息区，正常阅读不被吞掉。

消息定位仍使用实际 DOM 高度，只有横线的视觉分布改为紧凑等距排列。标记没有逐消息 DOM，流式内容不会重建标记列表。当前阅读高亮同步于消息区滚动，短对话自动隐藏，分支切换清理旧摘要和标记。

## 验证范围

- Light / Dark，1440×900、800×600、640×480。
- 默认无卡片、横线和空隙的 Hover 区分、空隙点击不跳转、用户 / AI 摘要、序号和位置、弹层边界及输入框避让。
- 点击、拖动、键盘、轨道滚轮、流式阅读位置、折叠 / 展开、短会话隐藏、当前分支切换。
- 120 条消息下导航 DOM 数量恒定；两条巨大消息保持紧凑轨道。
- 前端单元回归：88 / 88 通过；完整 Windows Edge 回归：64 / 64 通过。
- TypeScript、Vite 生产构建、Windows x64 NSIS 构建通过。实际 Release EXE 在隔离数据库下通过启动、字体设置保存、重复新建及关闭重启后的草稿恢复检查。
- 本轮只修改前端导航和样式，未修改 Rust、Provider、数据库 schema 或版本文件。
