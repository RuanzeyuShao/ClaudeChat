# ClaudeChat v0.1.5

2026-10-17 最新更新：长回答断流 / 网关异常受控恢复，同一 AI 节点接回正文，定期保存 SQLite 断点；手动继续不新增用户消息，来源复用、调用用量独立记录。保持版本 0.1.5。[恢复验证报告](../../docs/v0.1.5-recovery-report.md)。

已包含 8 套颜色主题与浅色 / 深色 / 跟随系统独立切换。入口为「设置 → 个性化」，即时生效并自动保存；恢复默认回到暖白翡翠浅色主题，保留 API、字体和聊天数据。[主题验证报告](../../docs/v0.1.5-themes-report.md)。

最新修复：滑轨移至聊天区左边缘，横线默认 6×2 px、间隔 8 px，仅 Hover 延长至 18 px。阅读高亮只改颜色，点击平滑滚动，移开恢复短线。版本保持 0.1.5。

当前安装包已包含极简导航优化：透明细横线轨道，仅命中横线时出现 Hover 预览卡片，空隙不误跳转。

2026-10-15 更新：新增可核对来源的句末上标引用和历史导航轨道，保留启动修复。无法确认映射的引用保留原文并提示，不猜测来源。版本号继续为 0.1.5。

点击 [下载 Windows x64 安装包](https://github.com/RuanzeyuShao/ClaudeChat/releases/download/v0.1.5/ClaudeChat_0.1.5_x64-setup.exe)，运行 `ClaudeChat_0.1.5_x64-setup.exe` 安装。更新前退出 ClaudeChat。

本版新增字体大小设置，修复新建对话重复产生空会话，支持长标题悬停滚动。字体设置入口：设置 → 通用偏好 → 字体大小。

2026-10-14 启动修复版已修复“本地数据未能载入 / 扩展键无效”。遇到此错误请重新下载并覆盖安装，无需卸载或删除聊天数据。

校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，构建信息见 [manifest.json](manifest.json)，完整验证说明见 [验证报告](../../docs/v0.1.5-test-report.md)。
