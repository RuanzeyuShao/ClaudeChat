# ClaudeChat v0.1.5

点击 [下载 Windows x64 安装包](https://github.com/RuanzeyuShao/ClaudeChat/raw/refs/heads/v0.1.5/installers/v0.1.5/ClaudeChat_0.1.5_x64-setup.exe)，运行 `ClaudeChat_0.1.5_x64-setup.exe` 安装。更新前退出 ClaudeChat。

本版新增字体大小设置，修复新建对话重复产生空会话，支持长标题悬停滚动。字体设置入口：设置 → 通用偏好 → 字体大小。

校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，构建信息见 [manifest.json](manifest.json)，完整验证说明见 [验证报告](../../docs/v0.1.5-test-report.md)。
